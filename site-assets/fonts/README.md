# WebberZone typography

These WOFF2 files are the WebberZone brand fonts used by the documentation
site. They are self-hosted so the site makes no Google Fonts request.

- [League Spartan](https://github.com/theleagueof/league-spartan) 700 for headings.
- [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) 400 and 500 for body and interface text.
- [Fira Code](https://github.com/tonsky/FiraCode) 400 for code.

The font files are distributed under their respective open-source font
licenses. The brand usage reference is the [WebberZone brand assets page](https://webberzone.com/brand-assets/).
